Kiểm tra pipeline bằng GitHub Actions

GitHub hỗ trợ quản lý mã nguồn Git và xem xét thay đổi qua pull request. GitHub Actions có thể tự động chạy kiểm tra khi mã thay đổi.

Ví dụ trong kỹ thuật dữ liệu

Khi có pull request sửa pipeline, một workflow có thể chạy kiểm thử Python trên dữ liệu mẫu và kiểm tra cấu trúc đầu ra trước khi hợp nhất thay đổi.

Lưu ý khi triển khai

Dùng dữ liệu mẫu có kết quả kỳ vọng rõ ràng, gồm cả trường hợp thiếu trường bắt buộc. Chạy kiểm thử trên dữ liệu mẫu để workflow không cần thông tin truy cập nguồn dữ liệu thật.
