# Profile website starter

A text-only HTML, CSS, and JavaScript starter derived from the original portfolio's console layout and dark theme.

## Run
Open index.html directly in a browser, or serve this folder with a local HTTP server. No dependencies or build step are required.

## Customize
- data/content.js: placeholder profile text, sections, and cards.
- css/colors.css: design tokens.
- css/template.css: starter-specific layout overrides.
- index.html: page structure, title, and description.
- js/main.js: text rendering and accessible tab navigation.

All personal content, images, icons, external fonts, social links, maps, and PDF generation dependencies have been omitted. Contact information and message submission are intentionally absent from this blank starter.

## GitHub Pages
Push the contents to your own repository, then configure Settings > Pages > Deploy from a branch and select the publishing branch with /(root).
